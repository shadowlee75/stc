3축 제원과 임계거리

임계거리 s_crit보다 짧은 구간은 정격속도에 도달하지 못해 삼각 프로파일이 됩니다. 이 설비는 주행 임계거리가 21.3 m로 길어 대부분의 주행이 삼각 프로파일입니다.

s_crit = v²/2 × (1/a + 1/d) 사다리꼴 (s ≥ s_crit) : t = s/v + v/2 × (1/a + 1/d) 삼각 (s < s_crit) : t = 2√(s/a) (a = d 인 경우)

읽어야 할 세 가지

복귀 운전(SC-return)은 쓰면 안 됩니다. 작업마다 정위치로 돌아가면 4절의 13.25 m 승강이 매번 낭비됩니다. 같은 2통로인데 달성률이 89.9%로 떨어지고 라인이 7시간 멈춥니다.
저장·반출 위치 규칙이 설비 대수만큼 중요합니다. 빈 셀을 아무 데나 쓰면 가동률 92.7%, 최근접 셀을 쓰면 72.7%입니다. 같은 하드웨어로 20%p 차이가 납니다. 여기에 가동률 η 0.9를 얹으면 전자는 이용률 103%로 넘치고, 후자는 81%로 여유가 남습니다.
이 부하에서는 복합사이클이 거의 성립하지 않습니다. 2통로에서 486회 중 DC로 묶인 것은 4회뿐이었습니다. 통로당 35+35 JPH면 크레인이 일을 마칠 때 보통 한쪽 작업만 밀려 있기 때문입니다. 계산서가 전제하는 “복합사이클 페어링”은 1통로처럼 포화된 경우에만 실효가 있습니다.

9결론

  • 도면의 2통로 구성이 최소입니다. 1통로는 달성률 53.6%로 요구 물동량의 절반만 처리합니다.
  • 2통로는 성립하지만 운전 방식이 여유를 좌우합니다. 최근접 저장·반출 규칙에서 가동률 72.7%(이용률 81%)로 여유가 있고, 임의 규칙에서는 92.7%(이용률 103%)로 여유가 없습니다.
  • 복귀 운전은 배제해야 합니다. 입출고구가 상·하로 갈린 이 배치에서는 치명적입니다.
  • 계산 자체는 검증되었습니다. FEM 2점법 · 셀 전수 열거 · 시뮬레이션 세 방법이 0.5% 이내로 일치합니다.
  • 다만 크레인 제원이 가정값입니다. 8절 1·2번을 확인하기 전까지는 이 결론을 잠정으로 두시는 편이 안전합니다.
